# Keo4 inventura pro Windows

Portable verze inventury pro Windows. Stačí stáhnout `Keo4 inventura.exe` z [GitHub Releases](https://github.com/shaman12345677/Keo/releases) a spustit.

**Toto není oficiální software společnosti ALIS.** Není to oficiální KEO4 ani oficiální čtečka od ALIS.

Podrobnosti, výměna souborů s KEO4 a sestavení jsou v hlavním [README](../README.md).
